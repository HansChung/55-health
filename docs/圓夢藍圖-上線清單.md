## 6. 章節開篇 0100（新增）

1. 若 `smart_sparks` 表已建，另執行 `supabase/add-chapter0100-source.sql`（允許 `source = chapter0100`）。
2. QR **0100** 指向：`https://nuan55.com/smart/chapter/0100`
3. 四入口：問一句 → 語音；拍一下 → 相機；找照片 → 相簿；記下一句話 → 光點表單（`source=chapter0100`）。
4. **不消耗 AI token** 的部份：章首頁、章首導讀文字、光點寫入；語音／拍照仍走既有配額。

## 15. 書本 × App 輕耦合（新增）

原則：**書教節奏；App 幫你再做一次，並留下痕跡。**

1. 若正式 DB 已有 `smart_sparks`，另執行 `supabase/add-chapter-opening-sources.sql`（允許 `source = chapterXXXX`）。
2. 各章節開篇頁有「**把這句話點成光點**」→ `/smart/spark?source=chapter{QR}`（需登入才保存）。
3. 首頁新增「**書本練習**」入口 → `/smart/guide`（智慧啟航／感官覺醒目錄）。
4. 從章節深連結進相機／語音時，上方顯示章節意圖提示（一拍、二問、三記下）。
5. 章首頁本身仍可離線練習與列印；只有「點成光點／在暖暖再試」才需要登入。
6. **能力標示**：每章有 `practiceWhere`（暖暖／手機／紙本／混合）與 `capabilityNote`，避免讀者以為 App 已有相簿搜尋、修圖、便條庫等專屬功能。

## 5. 和「智慧幸福檢測」的差別

- **檢測**：15 題打分數（R 仍是問卷裡的韌性題）  
- **圓夢藍圖**：日常小事點光點（R＝安全）  

兩套可以同時用，不會互相改分數。
