> 程式已寫好。你（Hans）只需在 Supabase 跑一段 SQL，部署後即可使用。  
> **R 軸＝安全**（防詐、查證訊息）。與「智慧幸福檢測」問卷並存，互不覆蓋。

---

## 1. 在 Supabase 建表（一定要做）

1. 開 https://supabase.com/dashboard/project/ydnvjqvstmprdciwkkyl/sql/new  
2. 打開專案檔案 `supabase/add-smart-sparks.sql`，全選複製  
3. 貼到 SQL Editor → 按 **Run**  
4. 看到 Success 即可  

---

## 2. 部署

把 PR 合進 `main`，等 Vercel 部署完成。

## 6. 章節開篇 0100（新增）

1. 若 `smart_sparks` 表已建，另執行 `supabase/add-chapter0100-source.sql`（允許 `source = chapter0100`）。
2. QR **0100** 指向：`https://nuan55.com/smart/chapter/0100`
3. 四入口：問一句 → 語音；拍一下 → 相機；找照片 → 相簿；記下一句話 → 光點表單（`source=chapter0100`）。
4. **不消耗 AI token** 的部份：章首頁、章首導讀文字、光點寫入；語音／拍照仍走既有配額。

## 5. 和「智慧幸福檢測」的差別

- **檢測**：15 題打分數（R 仍是問卷裡的韌性題）  
- **圓夢藍圖**：日常小事點光點（R＝安全）  

兩套可以同時用，不會互相改分數。
